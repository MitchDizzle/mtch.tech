# Working on Mitchtopia

Read `docs/12-design-flow.md` before changing site layout or interaction. It records
the user's design preferences; follow newer user instructions when they differ.

- Keep the title-card identity, fantasy font, warm palette, and window opening speed.
- Review changes in the context of the whole article on desktop and mobile.
- Keep project media author-positioned and article metadata at the end.
- Preserve the user's project writing and ongoing edits; change content only within the requested scope.
- Build with Eleventy and verify affected interactions before reporting completion.
- Report work as short, digestible bullets, noting whether `_site/` is ready to upload.
